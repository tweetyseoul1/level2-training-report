# 배포 방법 (딱 한 번만 하면 됩니다)

이 저장소는 GitHub Pages(정적 화면, `index.html`)와 별도로, 구글 계정에 있는
Apps Script 프로젝트("2급 수료증 및 자격발급 신청서")가 백엔드 역할을 합니다.
저는 원장님 구글 계정에 직접 접속해 배포할 수 없어서, 아래 순서를 원장님이 직접
진행해주셔야 합니다. 총 5분이면 끝납니다.

## 1. 새 코드 붙여넣기

1. https://script.google.com/ 접속 → "2급 수료증 및 자격발급 신청서" 프로젝트 열기
2. 왼쪽 `Code.gs` 파일을 열고 안의 내용을 전체 선택(Ctrl+A) 후 전부 삭제
3. 이 저장소의 [`apps-script/Code.gs`](./Code.gs) 파일 내용을 전체 복사해서 붙여넣기
4. 저장 (Ctrl+S)

## 2. 마이그레이션 1회 실행

1. 함수 선택 드롭다운에서 `migrateOnce_setupAdminAndInstructors` 선택
2. ▶ 실행 버튼 클릭 (처음 실행 시 권한 승인 창이 뜨면 허용)
3. 실행 로그(보기 → 실행 기록)에 "마이그레이션 완료" 메시지가 뜨면 성공
4. 이 작업으로 `사용자` 시트가 만들어지고, 관리자 계정(`admin` / 기존 비밀번호 `ai2026`)과
   기존 `강사계좌` 시트에 있던 강사들(김현희, 라지숙 등)이 임시 비밀번호 `0000`으로 등록됩니다.

## 3. 재배포 (URL은 그대로 유지)

1. 오른쪽 위 `배포` → `배포 관리`
2. 기존 배포 항목 옆 연필(수정) 아이콘 클릭
3. "버전"을 `새 버전`으로 변경 → `배포`
4. **주소가 바뀌지 않는지 확인** (`index.html`에 이미 넣어둔 주소와 동일해야 합니다)

## 4. 로그인 정보 확인/변경

- 원장님: 아이디 `admin`, 비밀번호 `ai2026` (로그인 후 원하시면 시트에서 직접 비밀번호를 바꿀 수 있도록
  나중에 "비밀번호 변경" 화면을 추가해드릴 수 있습니다. 지금은 시트의 `사용자` 탭에서 직접 관리)
- 기존 강사(김현희, 라지숙 등): 아이디 = 강사 이름, 임시 비밀번호 `0000`
  → 강사님께 이 정보를 안내해주시고, 로그인 후 "계좌정보" 탭에서 본인 계좌를 다시 확인하도록 안내해주세요.
- 새 강사는 원장님 화면의 "강사 관리" 탭에서 직접 아이디/비밀번호를 정해 등록하면 됩니다.

## 5. 첫 과정 만들기

1. `admin` 계정으로 로그인 → "과정 관리" 탭
2. 과정명, 담당 강사(드롭다운), 교육일시, 교육비 입력 → "과정 생성"
3. 생성된 과정 줄의 "링크 복사" 버튼으로 학생용 신청 링크를 받아 카카오톡 등으로 전달
4. "안내문 생성" 버튼을 누르면 과정명+강사명+계좌+링크가 자동으로 채워진 안내 문구가
   복사됩니다. 그대로 붙여넣어 학생들에게 전달하시면 됩니다.

## 참고: 무엇이 바뀌었나

- 예전에는 `apply.html`이 전체 강사 이름+계좌번호를 공개로 노출했습니다 → 이제는 과정 코드로
  들어온 학생에게 **그 과정의 담당 강사 1명 정보만** 보여줍니다.
- 예전에는 `mystudents.html?teacher=이름` 링크만 알면 아무나 그 강사의 수강생 개인정보를
  볼 수 있었습니다 → 이제는 로그인(세션 토큰) 없이는 아무 데이터도 조회할 수 없습니다.
- 강사 이름은 과정을 만들 때 원장님이 고정 배정하며, 학생/강사 모두 그 값을 바꿀 수 없습니다.
